# 🏆 SportifyUI

A simple, responsive sports-themed website built with **HTML**, **CSS**, and **Bootstrap (RTL)**.  
This project was developed as part of a university course to demonstrate front-end design and responsive layout skills.

---

## 🚀 Features

- Fully responsive design  
- RTL (Right-to-Left) support for Persian content  
- Multi-page structure (e.g. La Liga, Premier League)  
- Clean and minimal user interface built with Bootstrap  
- Lightweight static front-end — no backend required  

---

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3 / Bootstrap**  
- **jQuery**
